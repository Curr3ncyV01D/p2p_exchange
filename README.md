# 🚀 Инструкция по запуску P2P Обменника

## 1. Подготовка Telegram
1. **Бот**: Создайте бота в @BotFather, получите API Token.
2. **Группа Админов**: 
   - Создайте приватную группу.
   - В настройках группы включите «Темы» (Topics).
   - Добавьте бота в группу и дайте ему права администратора.
   - Узнайте ID группы (например, через бота @userinfobot).

## 2. Настройка окружения
Создайте файл `.env` в корневой папке по образцу:
```env
BOT_TOKEN=ваш_токен
ADMIN_GROUP_ID=-100... (ID вашей группы)
POSTGRES_DB=p2p_db
POSTGRES_USER=user
POSTGRES_PASSWORD=pass
REDIS_HOST=redis
```

## 3. Запуск (Docker)

Проект полностью автоматизирован. Убедитесь, что установлен Docker и Docker
Compose. Запустите команду:

```bash
docker-compose up -d --build
```

Бот сам создаст базу данных, применит настройки и начнет работу.

## 4. Управление (Админ-панель)

1.  Чтобы назначить себя администратором, после первого запуска найдите себя в
    базе данных (таблица users) и установите is_admin = True.
2.  В боте в разделе «Мой профиль» появится кнопка «🛠 Админ-панель».
3.  Функции админа:
      - Поиск пользователей по ID или Нику.
      - Выдача галочек «Верифицирован».
      - Блокировка (Бан).
      - Модерация объявлений (удаление/скрытие чужих заявок).

## 5. Арбитраж

Когда пользователь открывает спор, в вашей группе админов создается новая Тема.

  - Пишите прямо в эту тему, чтобы ваши сообщения доставлялись участникам
    сделки.
  - Используйте кнопки вверху темы, чтобы закрыть спор в пользу одной из сторон.
